\doxysubsection{Detailed Description}
Класс, представляющий игру. 

Этот класс управляет игровым процессом, включая игровую доску, колоду карт и игральные кости. Он отвечает за инициализацию игры и ее запуск.

Конструктор игры.

Этот конструктор инициализирует объекты доски, колоды и игральных костей.

Этот конструктор инициализирует игру, создавая колоду карт и добавляя в нее различные типы карт.

В колоду добавляются карты строительства, природных катастроф, экономических событий, политических событий, событий с изменением значений и событий торговли.
