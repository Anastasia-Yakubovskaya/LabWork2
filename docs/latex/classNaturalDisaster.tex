\doxysubsection{Detailed Description}
Класс, представляющий природное бедствие. 

Этот класс наследует от класса \mbox{\hyperlink{classEventCard}{Event\+Card}} и представляет карту события, связанного с природным бедствием, которое может нанести урон игрокам или игровому полю.
