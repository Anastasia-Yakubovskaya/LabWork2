\doxysubsection{Detailed Description}
Класс, представляющий колоду карт. 

Этот класс управляет колодой карт, включая строительные карты, карты событий и бонусные карты. Он предоставляет методы для добавления карт, перемешивания колоды и вытаскивания карт.
