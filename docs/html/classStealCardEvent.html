Detailed Description

Класс, представляющий событие кражи карты.

Этот класс наследует от класса BonusCard и представляет событие, при котором игрок может украсть карту у другого игрока.

Активирует событие кражи карты.

Активирует эффект карты кражи.

Этот метод выполняет логику кражи карты у целевого игрока и обновляет состояние игры на доске.

Parameters
boardСсылка на игровую доску, на которой происходит событие.
currentPlayerУказатель на текущего игрока, который инициирует событие.

Этот метод позволяет текущему игроку украсть объект у целевого игрока. Объект выбирается случайным образом из всех объектов целевого игрока на игровом поле.
