Detailed Description

Класс, представляющий событие с переменной величиной.

Этот класс наследует от класса BonusCard и представляет событие, которое может нанести урон целевому игроку.

void VarEvent::trigger ( )

Активирует событие.

Активирует эффект карты VarEvent.

Этот метод выполняет логику события, нанося урон целевому игроку.

Этот метод уменьшает счет целевого игрока на указанное значение урона. Если цель не установлена, выводится сообщение об ошибке.
