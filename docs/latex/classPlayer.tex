\doxysubsection{Detailed Description}
Класс, представляющий игрока в игре. 

Этот класс наследует от класса \mbox{\hyperlink{classPlayerBase}{Player\+Base}} и предоставляет функциональность для управления картами игрока, включая возможность тянуть карты из колоды и отображать свою руку.
