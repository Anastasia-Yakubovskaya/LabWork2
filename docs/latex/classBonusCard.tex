\doxysubsection{Detailed Description}
Класс, представляющий бонусную карту. 

Этот класс наследует от \mbox{\hyperlink{classCard}{Card}} и представляет бонусные карты, которые могут быть использованы игроками для получения различных преимуществ в игре.
