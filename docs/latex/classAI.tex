\doxysubsection{Detailed Description}
Класс, представляющий искусственный интеллект игрока. 

Этот класс наследует от \mbox{\hyperlink{classPlayerBase}{Player\+Base}} и реализует логику для действий, которые может выполнять искусственный интеллект в игре, такие как взятие карт и отображение своей руки.
